# 0.5.1 音轨选择修复

修复 YouTube 多语言视频可能默认选到其他语言配音的问题。自动选择优先原声，其次网站默认音轨；同一优先级下优先未经动态压缩的版本，再考虑编码搭配和码率。手动选择的音轨仍按用户选择下载。

音频列表显示语言、原声或默认标记，并区分音量动态压缩版本。多语言视频新增“音轨语言”筛选，音频格式仍按编码分组。主信息栏同时显示选定音轨的语言。

图中《库克时代》的相似条目是普通与动态压缩音轨。《I Let Astra Run Blender + Higgsfield》的实际解析包含 21 种语言、147 个音频格式，其中英语是原声。旧界面隐藏语言且按码率选择，导致条目相似并可能选错配音。

安装后重新粘贴链接并解析。在“高级设置 → 音轨语言”确认原声或选择需要的语言，然后下载。此前已下载的文件不会自动改变；旧等待任务可能保留旧音轨选择，建议移除旧任务后重新添加。不同音轨遇到同名文件时按提示另存。

这次修复针对选错音轨，不等于已确认或修复所有音画时间偏移问题。
