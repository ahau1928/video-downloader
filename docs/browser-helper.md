# Edge / Chrome 浏览器助手使用说明

不需要更换 Firefox，也不需要关闭 Edge / Chrome。配套扩展通过浏览器接口，在你点击授权后将当前网站的 Cookie 交给本机下载器，避免直接复制浏览器的 Cookie 数据库。

## 首次设置（每台电脑一次）

1. 安装 Releases 中的最新 Windows 安装包，打开软件。
2. 进入“设置 → 网络与账号”，点击“启用浏览器连接”。这一步为当前 Windows 用户注册 Edge / Chrome 本机通信连接，不需要管理员权限。
3. 点击“打开配套扩展文件夹”。记下打开的文件夹路径；安装包已经包含扩展，通常无需另行解压 ZIP。
4. 在 Edge 地址栏输入 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”；Chrome 对应地址为 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”。不同版本的文字可能稍有不同。
5. 选择第 3 步的文件夹（里面应直接有 `manifest.json`）。也可以解压配套 ZIP 到固定目录后加载；不要删除或移动已加载的目录。
6. 将“视频下载器 · 浏览器助手”固定到浏览器工具栏，点击它，再点“检测下载器连接”。应显示“下载器已连接”。

本版本是本地加载的扩展，尚未上架扩展商店。不能仅靠安装 EXE 就自动安装、授权浏览器扩展。软件和浏览器应使用同一个 Windows 账号。升级或移动软件后，如果无法连接，重新点击一次“启用浏览器连接”。扩展代码更新后，可在扩展管理页点击重新加载。

## 日常使用

1. 在惯用的 Edge / Chrome 普通窗口中打开 YouTube 或 Vimeo 视频。网站要求登录或验证时，在网站里正常完成。
2. 点击工具栏中的浏览器助手，选择“授权并发送视频”，接受当前网站所需权限。
3. 回到下载器“下载”页面，视频会进入“等待开始”状态，点击“开始等待任务”。使用软件的默认画质与输出设置。
4. 如果需要先手选视频流和音频流：在扩展中选“仅更新登录信息”，然后将视频链接粘贴到下载器中解析和选择。

软件关闭时也可以发送；下次打开软件后，链接会加入等待队列。请先设置有效的下载目录。发送重复的等待任务时，软件会按原有规则去重。

## 已经报错的链接

在对应网站登录后，扩展选择“仅更新登录信息”。对于输入框里的链接，点击“重新解析”；对于失败队列任务，点击“重试”。不必重新读取 Edge / Chrome 数据库。

“设置 → 网络与账号”中的网站授权会显示来源与保存时间。“已保存”只表示获取到了 Cookie，不代表网站已经确认登录有效。可以在下方粘贴具体视频链接，点击“检测视频访问”，查看实际解析结果。

建议将“直接读取浏览器（备用）”设为“不使用”，避免未授权的网站再次尝试读取受锁定或加密保护的浏览器数据库。已保存的本站授权始终优先使用。

## Cookie 文件备用入口

如果无法安装本地扩展，可从你信任的浏览器 Cookie 导出工具取得 Netscape 格式的 `cookies.txt`，然后点击 YouTube 或 Vimeo 行对应的“导入 Cookie 文件”。程序只保留所选网站的条目，不需要导出所有网站的数据。

Cookie 相当于登录凭据，请只在自己的电脑上导入，不要发给别人或上传到聊天。原始导入文件仍归你管理；确认导入成功后可自行删除不再需要的文件。

## 常见情况

- **无法连接下载器**：确认软件是 0.3.0 或更新版，点击“启用浏览器连接”；确认加载的是配套扩展，并与软件使用同一 Windows 用户。
- **未发现 Cookie**：在当前普通窗口中登录相应网站后重新授权；首次需允许扩展访问该网站。
- **YouTube 仍要求确认真人**：确保浏览器与下载器使用相同代理线路，在网站完成验证后重新授权。Cookie 不保证能通过所有站点验证。
- **Vimeo 仍要求登录**：确认登录的是 Vimeo，而非仅登录了浏览器账号；重新授权后用“检测视频访问”检查该链接。
- **发送后看不到任务**：打开软件，检查下载目录是否存在、当前列表是否切到了“全部”，并查看是否有错误提示。
- **要撤销**：点击网站对应的“清除授权”；同时将“直接读取浏览器（备用）”设为“不使用”。正在执行的任务可能仍持有本次临时登录文件，可取消任务让它结束并清理。浏览器扩展的站点权限可在扩展管理页撤销，或移除扩展。

## 隐私与实际限制

- 扩展仅支持 YouTube / Vimeo；只有点击授权按钮才读取对应网站 Cookie，不读取其他网站、密码或浏览历史。
- Cookie 通过 Native Messaging 传给本机软件，不上传到开发者服务器。下载时，yt-dlp 按 Cookie 域名将其用于对应网站的请求。
- 长期保存的登录信息使用 Windows 当前用户 DPAPI 加密。为兼容 yt-dlp，执行任务期间会生成临时 Cookie 文件，正常结束、失败或取消时自动清理。系统崩溃或强制结束进程可能留下临时文件，位于 `%APPDATA%\com.jasonpan.video-downloader\browser-auth\temporary`；确认软件与下载进程均已退出后，可清理该目录中的文件。
- 登录会过期、轮换，网站接口和验证规则也会变化。此方案解决浏览器数据库读取障碍，不能承诺所有视频永远下载成功。
- 保留工具自动更新。本次继续内置 yt-dlp 2026.08.19、FFmpeg / FFprobe 9.0.1、Deno 2.9.6 与 yt-dlp EJS 0.8.0。
