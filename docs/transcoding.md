# 视频下载器 0.4.0

本版升级本地转码功能。关闭旧版后运行[Releases 中的安装包](https://github.com/ahau1928/video-downloader/releases/tag/v0.4.0) 安装，打开后左下角应显示 v0.4.0。已有设置和下载历史沿用，浏览器助手保持兼容，无需重新安装扩展。

## 开始转码

1. 打开“转码”，拖入本地视频，或点击添加。添加区会变成文件列表，可以继续添加、逐项移除或一键清空。
2. 选择视频编码、压制方式、预设、音频处理及输出设置。每个文件下方显示输出名称；目标大小模式还显示音频占用和视频可用码率。
3. 等待输出检测完成，点击“开始转码”。本批文件进入队列后设置固定，随后修改参数只影响后续添加的任务。
4. 在任务详情查看结果或错误，完成后点击文件夹图标找到文件。暂停中的转码会停止，继续时重新编码。

清空上方待转码文件不会取消下方队列。下方队列的清除与移除仍按原来的任务规则工作。

## 默认设置

| 设置 | 默认值 |
| --- | --- |
| 编码 / 压制方式 | H.264 / CRF 23 |
| H.265 的独立 CRF | 28 |
| 压制预设 | 中等 medium |
| 音频 | AAC 192 kbps |
| 分辨率 / 帧率 | 保持源视频 |
| 自定义尺寸 | 默认锁定宽高比 |
| 封装 | MP4 |
| 文件名 | 自动添加编码和压制方式后缀 |
| 输出目录 | 原文件旁边 |

“保存为默认设置”保存当前参数。本地转码设置独立于下载页的“自动转码 · H.264 MP4”。

## 视频与目标大小

- 编码支持 H.264、H.265，均使用软件编码。H.265 对播放、剪辑软件的解码支持要求较高。
- CRF 控制画质，数值越低通常画质越高、体积越大。两个编码分别记忆 CRF 和预设；相同 CRF 数值不代表两种编码具有相同画质。
- 目标大小按**每个文件**设置，支持 MB / GB（十进制，1 GB = 1000 MB）。例如选择 100 MB，列表中的每个文件均以 100 MB 为目标。
- 目标模式执行两遍编码：先分析，再生成文件。扣除所选音频的占用并预留 2% 封装空间后，计算视频平均码率。提高音频码率会减少视频的可用码率。
- 复制音频时扫描音频包的实际大小，长视频检测可能较慢。预算不足时禁止开始并给出提示。
- 目标大小不是严格的文件大小上限，编码器、内容和封装会带来偏差。任务详情记录实际大小与偏差；特别简单、很短的视频可能明显小于目标。
- 预设提供极速、很快、快速、中等、慢速、很慢。越慢通常压缩效率越高，但耗时增加。

## 音频

- **压制音频**：输出 AAC，可选择 96 / 128 / 160 / 192 / 256 / 320 kbps、自定义 16～512 kbps，或参考源音频码率。参考原码率仍是重新编码；源音频码率未知或超出支持范围时需指定码率。
- **复制音频流**：不重新编码音频。所选封装不支持该音频时，开始前提示改选 AAC 或 MKV，不会悄悄更改选择。
- **无音频流**：仅输出视频，目标大小预算全部供视频及封装使用。

当前输出选取第一条普通视频流和第一条音轨，不带入其他音轨、字幕或章节。需要保留这些内容时保留源文件。

## 分辨率、色彩与输出

- 保持原分辨率，或分别输入宽高。会考虑视频旋转与像素宽高比，并将输出对齐至偶数尺寸。
- 锁定宽高比时，按最后编辑的宽度或高度，分别根据每个源视频比例计算另一边。最终输出尺寸以各文件预览为准。
- 解锁时可选择等比补边、裁剪填满或拉伸。放大分辨率不会增加源视频细节。
- HDR / 高色深视频默认要求明确选择保留或转为 SDR。保留高色深需 H.265，最高 10 位；HDR 转 SDR 会进行色调映射并输出 8 位。
- 当前不支持完整保留 Dolby Vision / HDR10+ 动态元数据，静态 HDR 元数据也不保证全部保留；界面会提示，建议保留源文件。
- 封装支持 MP4、MKV、MOV。容器变化不等于编码变化。
- 自动后缀示例：`视频_H264_CRF23.mp4`、`视频_H265_100MB_1280x720.mkv`。也可手动输入或不添加后缀。
- 同名文件自动编号，始终避免覆盖已有文件。临时工作文件在任务结束后清理，失败不会删除源文件。取消“保留源文件”时，只有输出校验并发布成功后才删除输入。

## 本版验证

- 前端类型检查与生产构建通过；26 项 Rust 单元测试通过。
- 14 组真实工具集成检查通过，结果见Release 附件 `integration-test-result.json`。
- 实测覆盖 H.264 / H.265、MP4 / MKV / MOV、AAC 编码、复制音频包 SHA256 一致、无音频、分辨率补边、后缀、HDR 10 位保留及转 SDR 8 位。
- 8 秒测试视频目标 0.5 MB：H.264 输出 497287 字节，H.265 输出 497953 字节。该测试不代表所有素材都具有相同偏差。
- 原有下载、同名处理、暂停与续传、队列持久化、浏览器授权及临时文件清理回归通过。
- 界面控件在浏览器模拟文件接口下检查；编码结果由真实 FFmpeg 测试验证。本次未在另一台电脑上执行安装测试。

内置依赖沿用已核验的 yt-dlp 2026.08.19、FFmpeg / FFprobe 9.0.1、Deno 2.9.6、EJS 0.8.0。软件仍支持在“工具与更新”中检查更新。

浏览器登录授权的操作见[浏览器助手使用说明](browser-helper.md)，本版不改变已有授权方式。
