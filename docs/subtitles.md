# 字幕下载（0.5.0 起）

支持将网站提供的原生字幕、自动生成字幕及自动翻译字幕保存为 UTF-8 SRT。支持英文、中文（优先简体）和中英双语。

## 随视频一起下载

1. 粘贴视频链接。
2. 勾选“同时下载字幕 · SRT”，选择字幕语言和来源。
3. 点击“下载”。字幕与最终视频保存到同一目录，并沿用视频文件名。

字幕选项也适用于批量添加；已加入队列的任务使用添加时的选项，不受之后修改影响。

## 只下载字幕

把“输出方式”切换为“仅字幕 · SRT”，选择语言和来源，粘贴链接后点击下载。不下载视频，可以用来给已有视频补字幕。

## 字幕来源

- **优先原生，缺失时自动字幕**：每种语言优先选择上传者提供的字幕，没有时选择网站自动生成或翻译的字幕。推荐使用。
- **仅原生字幕**：只使用上传者提供的字幕，缺少所选语言时提示失败。
- **仅自动生成 / 翻译字幕**：只使用网站提供的自动字幕，不回退到原生字幕。

中文优先简体，只有繁体可用时保留繁体，不擅自转换。自动识别和自动翻译的准确性取决于网站；本软件不在本地运行语音识别或额外付费翻译服务。网站没有提供所选语言时，会明确提示，不生成空字幕或虚构翻译。

## 双语文件

选择“中英双语”时保存三份文件：

```text
视频标题.zh.srt       中文
视频标题.en.srt       英文
视频标题.zh-en.srt    中英双语
```

双语字幕按时间轴对齐，中文在上、英文在下；不会简单按照条目序号拼接。若两种字幕的时间范围不同，局部可能只显示一种语言。SRT 不包含原网站的字体、颜色、位置等样式。

播放器或剪辑软件中可以手动导入 `.zh-en.srt`。同名同内容字幕会复用；同名但内容不同的文件会自动编号，保留旧文件。只下载字幕时，文件名使用视频标题。

## 失败、暂停和重试

- 字幕失败时，已保存的视频保留。任务详情提供“仅重试字幕”，无需重新下载或转码视频。
- 网站限流（如 HTTP 429）可稍后重试；授权问题可通过现有浏览器助手重新授权。
- 暂停会终止当前字幕获取；继续后重新获取字幕，已保存的视频不会因此丢失。
- 字幕解析、下载和转换使用临时目录，成功或失败退出后会清理临时内容。

实现使用 [yt-dlp 字幕选项](https://github.com/yt-dlp/yt-dlp#subtitle-options) 和 FFmpeg 转换，优先获取 VTT 再转换 SRT，以兼容 YouTube 自动翻译字幕。
